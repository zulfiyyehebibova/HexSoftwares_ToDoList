📝 To-Do List App | HexSoftwares Internship — Project 1

A functional and interactive To-Do List application built as part of my HexSoftwares web development internship program.

🚀 Features
- Task Management: Add, delete, and mark tasks as completed.
- Data Persistence: Uses Local Storage to keep tasks saved after page reloads.
- Interactive UI: Dynamic DOM manipulation for smooth user experience.
- Responsive Design: Optimized for desktop and mobile devices.
- Task Status Indicators: Clear separation between completed and pending tasks.

🛠️ Technologies
- HTML5 — Semantic structure
- CSS3 — Styling and responsive layout
- JavaScript (Vanilla JS) — Logic, DOM manipulation, Local Storage
